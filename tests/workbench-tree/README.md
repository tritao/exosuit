Run with `haxeon/scripts/haxeon run --project tests/workbench-tree/haxeon.json`.

Checks the Workbench as one tree (docs/architecture/0006-workspaces-without-folders.md): the machine's workspaces in exohost's order, status lines and New Workspace…, and under every workspace's row its groups, sub-groups, terminals and sessions by one rule, keyed by workspace and item (`g:<workspace>|<id>`). A workspace's rows come from its link's lists once read, else from a copy of its catalog, under the same keys; only a source that changed is laid out again, and only the open workspace and expanded ones are projected. Covers an empty machine, exohost still answering or failing, a device's granted workspaces (no New Workspace…), a folderless workspace open on its scratch folder, cyclic groups, and the right panel's scope, which follows only the open workspace's rows. A workspace's row with nothing under it gets a note row: "No sessions yet", "Loading…", "Not running" or why the window could not connect. A real TreeView checks the rendered order, that only the open workspace starts expanded, that expanding a closed workspace only expands it (its note says it is loading), and the accessibility labels that name the workspace and the group.
