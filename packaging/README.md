# Pragtical Haxeon

Run `./pragtical-haxeon [file-or-directory ...]` from any working directory.
The archive contains its HashLink modules, bundled language server, fonts,
reference defaults, documentation and license notices.

Linux requires compatible SDL 3, FreeType and HarfBuzz shared libraries. User
configuration and state follow the platform paths documented in
`docs/configuration.md`; set `PRAGTICAL_PORTABLE` to keep both under one chosen
directory.
